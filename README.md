# SM64 Vision

SM64 Vision brings a landmark 1996 3D platformer to Apple Vision Pro as a spatial experience: not a flat picture pinned in front of you, but a world you can look into and step inside.

Join the TestFlight: https://testflight.apple.com/join/p2cHPRZd

## Repository status

This repository currently does not host the source code for SM64 Vision. For now, it exists only for bug tracking, feedback, and public project information.

Please use GitHub Issues to report bugs, share feedback, or describe problems you run into while testing the app.

## Five ways to play

- **2D Window** - The game on a floating screen, exactly as it always looked.
- **3D Window** - The same framing, given real depth. This mode is currently in beta.
- **3D Portal** - A window into the world. The camera sits on the glass, so moving your head lets you see sideways past the frame, the way a real opening behaves.
- **3rd-Person VR** - The frame falls away and the world fills your field of view. This mode is currently in beta.
- **First-Person VR** - You stand where the character stands. He runs where you look, and the right stick turns your heading in 30-degree steps, which keeps it comfortable.

## Built for the headset

- A true stereo pair is computed per eye from the live head pose at display rate, so head motion stays smooth no matter how the game itself ticks.
- Grab the window with a pinch to move it, and use both hands to resize it.
- Live controls for stereo depth, antialiasing, and supersampling take effect without a restart.
- Full support for MFi and PlayStation controllers.
- A 360-degree sky closes overhead and underfoot, so there is somewhere to look in every direction.

## You supply the game data

This app contains no game content of any kind. It is a build of an open-source reimplementation of the original engine, and it needs a ROM image of the 1996 US release, which you must create yourself from your own original cartridge.

Nothing is downloaded, offered, or shared. You choose the file once, it is copied into the app's own folder, and it stays on your device.
